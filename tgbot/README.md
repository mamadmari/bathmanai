# btm-bot — ربات مدیریت سرویس

ربات تلگرامی فارسی برای فروش و مدیریت سرویس اتصال، روی پنل **NX** — بدون هیچ وابستگی npm.

## قابلیت‌ها

- منوی شیشه‌ای فارسی/RTL با دکمه‌های درون‌خطی و اموجی
- خرید سرویس با کیف پول (کارت‌به‌کارت + رسید عکس، تأیید مدیر)
- سرویس‌های من: حجم، مصرف، روز باقی‌مانده، لینک اشتراک و کانفیگ مستقیم
- تمدید و افزایش حجم بدون تغییر لینک کاربر
- کیف پول، تاریخچه سفارش‌ها، دعوت دوستان با هدیه نقدی
- پشتیبانی (متن/عکس) با رله به مدیر
- پنل مدیر داخل خود ربات (`/admin`): تأیید/رد رسید، آمار، کاربران، شارژ دستی، سرویس هدیه، پیام همگانی، تنظیمات کارت و پشتیبانی، حالت تعمیرات
- یادآوری خودکار انقضا (۳ روز مانده و منقضی‌شده)
- دو حالت اتصال: **polling** (پیش‌فرض، هیچ پورتی باز نیست) یا webhook روی مسیر تصادفی با هدر Secret

## پیکربندی

فایل محیطی `/etc/btm-bot.env` با مجوز `600` (نمونه: `env.example`).

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `BOT_MODE` | `poll` یا `webhook` |
| `ADMIN_IDS` | آی‌دی عددی مدیران، جداشده با کاما (خالی = اولین `/start` مالک می‌شود) |
| `NX_BASE` | آدرس پنل روی لوکال‌هاست |
| `NX_TOKEN` | توکن API پنل (Access → API tokens) |
| `NX_TEMPLATE_ID` | شناسه قالب نود |
| `SUB_PREFIX` | پیشوند اختیاری برای لینک اشتراک |
| `DB_PATH` | مسیر فایل JSON پایگاه داده |

## نصب

```bash
mkdir -p /opt/btm-bot /var/lib/btm-bot
cp -a src package.json /opt/btm-bot/
cp btm-bot.service /etc/systemd/system/
cp env.example /etc/btm-bot.env && chmod 600 /etc/btm-bot.env   # مقادیر را پر کنید
systemctl daemon-reload && systemctl enable --now btm-bot
journalctl -u btm-bot -f
```

## امنیت

- هیچ راز/توکنی در مخزن نیست؛ همه از فایل محیطی خوانده می‌شود.
- در حالت polling هیچ پورت عمومی و هیچ مسیر وبهوکی وجود ندارد.
- اگر webhook لازم شد: مسیر ۲۴ کاراکتری تصادفی + هدر `X-Telegram-Bot-Api-Secret-Token`.
- داده‌ها در `/var/lib/btm-bot/db.json` با نوشتن اتمیک و مجوز 600.
